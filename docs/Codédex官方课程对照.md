## 四、风格差异

| | Codédex | 我们 |
|---|---|---|
| 前几关 | **打字练习**：数字金字塔、字母画、整封 25 行的 ASCII 信 | 从第 1 关就写有意义的输出 |
| 数学味 | **很重**：F→C、BMI、勾股、求根公式、汇率、股票 | 只有体温计一关是数学 |
| 练习长度 | 偏长：分院帽 100+ 行、Pokédex、99 Bottles 都是几十行 | 一关一个概念，3~15 行 |
| 判分 | 网站里判，仓库只放答案 | 有判分、分层提示、参考解、卡片成色 |
| 找 bug | 没有 | 5 关 |
| BOSS | Checkpoint / Final Project + 导师批改 + 证书 | 每区一个 BOSS 关 |
| 付费 | 第 3 章起要会员 | 全免费 |

**它最特别的一点**：前 3 关（Pattern / Initials / Snail Mail）是纯粹的"精确打字 + 多行 print"训练，要你照着画图形。这个思路我们完全没有 —— 它练的是"手别抖、标点别错"，挺有效但很枯燥。

## 五、结论与补齐记录

**结论**：
- 覆盖面**互有长短**，不是谁包含谁。我们的数据结构更宽（多出 dict/tuple/set），它的运算符更全（多出 `%`、`**`、`+=`、切片）。
- 我们多 7 关（40 vs 33），但我们的关卡更短、更聚焦。
- 它练"打字和数学"，我们练"概念和排错"。

**建议补的（按优先级）**：

| 优先级 | 补什么 | 塞进哪一关（不用加新关） |
|---|---|---|
| 🔴 必补 | `%` 取模 | 第 6 关「数字家族」—— 讲完 int/float 顺带说"还有个 `%` 给你除法余数" |
| 🔴 必补 | f-string | 第 9 关「变形术」—— 这关正好在讲"文字和数字不能直接拼"，f-string 就是正道解法 |
| 🟡 建议 | `+=` | 第 29 关「数不清的时候」—— 那里本来就有 `n = n - 1`，顺带提 `n -= 1` |
| 🟡 建议 | 切片 | 第 12 关「第一个列表」—— 讲完索引顺带说"还能一次取一段" |
| 🟢 可选 | `pop()` | 第 13 关「往里加东西」—— 和 remove 放一起对比 |
| 🟢 可选 | `**` | 第 6 关「数字家族」—— 和 `%` 一起提 |

**八个缺口全部塞进了现有的 7 个关卡，没有新增关卡，40 关的编号、XP、等级门槛、地图一律没动。**

补齐后还做了一层保障：判题引擎新增了 `_code`（学员源码）供判分读取，所以这八项是**真的"必须动手用"**——用别的写法输出一样也会被判不过，报错信息会告诉你该用什么。

## 六、还值得学的一招

Codédex 第一章那三个"打字关"（Pattern / Initials / Snail Mail）思路可以借鉴：
**让学员用 print 画出一个图形**，练的是"标点符号一个都不能错"。

我们现在的关卡都在求"输出对"，但没有一关专门练"大段精确输入"。如果以后想加，可以做成某个区的进阶挑战。
