## 这一轮修掉的两个真 bug

**① `runner.py` 被截断（引擎完全起不来）**

根因：我用 JS 的 `String.replace` 去拼 Python 文件，而替换文本里包含 `$'` ——
`$'` 在 JS 里是**特殊替换模式**（表示"匹配之后的全部内容"），于是 Python 文件被切开重排：
`re.sub` 那行断在半路，残留的 `, '', msg)` 掉到了文件末尾。整个 runner 是语法错误，
Pyodide 加载时抛异常，引擎静默卡在"加载中"。

**② 引擎加载失败被静默吞掉**

worker 上报 `ready:false` 时，主线程只处理了 `ready:true` 的分支，失败没有任何出口。
现在 `Judge.onStatus()` 会把 `failed` 和错误信息抛出来，界面直接显示原因。

## 关键设计决定

| 决定 | 理由 |
|---|---|
| 总数从内容算出，不写死 | 现在显示 `0 / 60`、`4 / 4 关`、`1 / 1 徽章`，随内容增长自动变 |
| 解锁规则：全局线性 | 做完上一关解锁下一关，最简单也最不容易出岔 |
| 地图只画第一季 6 个区域 | 13 个节点挤一张图，图标会缩到看不清；第二季 7 个列在侧栏 |
| 判分用例的 `assert` 第二个参数 | 就是给学员看的话，会把学员的实际值打进去 |
| 卡片成色：不看提示不通答案 = 金 | 不惩罚失败，只影响成色，给"回头打金牌"的动力 |
